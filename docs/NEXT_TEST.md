# Next installed-build test — 0.2.1 beta

Start with [Getting started & troubleshooting](TESTER_GUIDE.md). Maintainers should record results in the [release checklist](RELEASE.md); automated results are summarized in [the security review](SECURITY_REVIEW.md).

Before declaring this beta ready for wider use, test fresh installation, fresh sign-in with verification, two books (one requiring search), account switching, private mode, interrupted sign-out and cleanup retry. Also test book-specific drafts, edit/delete and explicit current/old note exports using synthetic notes. Do not share account data or full browser logs.

When checking playback, compare the actual chapter and time against the regular Audible browser/mobile app. A visible chapter name alone does not prove synchronization or playable audio. Do not erase local data to troubleshoot a missing position or note.
